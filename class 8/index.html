Condition Statements

Condition statements are used to perform different actions based on different conditions

  • if statement: Executes a block of code if a specified condition is true.
  • else statement: Executes a block of code if the condition in the if statement is false.
  • else if statement: Specifies a new condition to test if the first condition is false.
  • switch statement: Evaluates an expression and executes code based on matching case values.

Loop Statements

Loop statements are used to execute a block of code repeatedly

  • for statement: Executes a block of code a specified number of times.
  • while statement: Executes a block of code as long as a specified condition is true.
  • do...while statement: Executes a block of code once, and then repeats the loop as long as a specified condition is true.
  • for...in statement: Executes a block of code for each property in an object.
  • for...of statement: Executes a block of code for each element in an iterable object.
